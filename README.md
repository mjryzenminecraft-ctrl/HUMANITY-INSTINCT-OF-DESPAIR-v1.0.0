# 🎭 HUMANITY: INSTINCTS OF DESPAIR

Welcome to **HUMANITY: INSTINCTS OF DESPAIR**! Immerse yourself in a choice-driven narrative adventure built entirely in Python using an advanced modular architecture.

---

## 🚀 Quick Start (No Python Setup Needed!)

You don't need Python or VS Code installed to play this game. It is fully compiled as a standalone desktop application.

1. Navigate to the **Releases** section on the right side of this page.
2. Download the latest **`HUMANITY.zip`** bundle.
3. Extract (unzip) the folder anywhere on your computer.
4. Open the folder and double-click **`HUMANITY.exe`** to play instantly!

---

## 🕹️ Game Features
* **Modular Story Engine:** Features dynamic narrative branches managed directly through custom logic files.
* **Immersive Experience:** Includes custom audio and state-tracking integrations (`despair.audio`, `despair.player`, `despair.choices`).
* **Clean Launch:** Fully packaged to run as a clean desktop window with zero command terminal pop-ups.

---

## 🛠️ Built With
* Python 3.14
* Pygame Community Edition (`pygame-ce`)
* Compiled via PyInstaller
